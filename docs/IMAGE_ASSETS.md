# Image assets

The workspace backdrop was generated using the built-in image generation tool (imagegen skill). The final asset is `public/graphics/stratos-atmosphere.png` and is consumed locally by the workspace CSS. No remote image service is needed.

Final prompt:

> Use case: stylized-concept. Asset type: subtle wide atmospheric background for a premium dark project workspace UI. Generate an abstract computational landscape: fine luminous blue contour lines forming sweeping topographic waves in dark midnight space, softly volumetric indigo mist, sparse tiny pale blue stars, an elegant low curved horizon. Restrained, sophisticated, high quality generative data art, no planets, no people, no objects, no text or logos. Wide landscape composition, strongest detail in upper third, bottom fades into nearly black charcoal, generous quiet negative space. This is background art, not a UI screenshot.

Project cards use a complementary deterministic SVG system, generated by `python3 scripts/generate-project-art.py`. Atlas has an orbital wireframe; Orion has flowing trajectories; Beacon has layered documents; Quartz has a connected crystalline network. The original starter artwork remains available; the interface uses the `*-v2.svg` files.
