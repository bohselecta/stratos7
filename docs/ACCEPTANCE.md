# Demo Acceptance Criteria

A build is demo-ready when:

- North Star three-column composition is recognizable at 1440px+
- Project panel can open/close and switch tabs
- Atlas Console fixture project is the default
- project switching changes only fictional fixture state
- one approval can be reviewed and approved or sent back
- approval completion creates a visible receipt/state change
- running task can pause/resume
- Tasks, Runs, and Files tabs have working detail states
- right panel can be widened and remains usable
- mobile/tablet layout does not overflow
- keyboard focus is visible on all controls
- no console errors in the canonical demo flow
- no real-user data appears anywhere in the rendered product
- main demo flow works offline after dependencies are installed
